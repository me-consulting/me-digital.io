# ME Digital — me-digital.io

Repository für die Domain **me-digital.io** und die Website von **ME Digital**
(IT-Consulting & Software-Entwicklung, Fokus Frontend & KI).

## Zweige (branches)

- **`main`** — Platzhalter-Startseite (Hello-World). Dient dazu, die Domain /
  GitHub Pages sofort zu konfigurieren und zu testen.
- **`develop`** — die vollständige Website (Angular, neu). Wird hier
  entwickelt; fertiggestellt landet sie später in `main`.
